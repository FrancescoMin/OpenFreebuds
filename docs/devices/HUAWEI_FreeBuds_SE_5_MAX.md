# HUAWEI FreeBuds SE 5 MAX

Protocol: Huawei SPP, port 1

Hardware platform: `BTFT0026K` (submodel: `BTFT0026-00017D`, hardware: `Cyw8c`)

Tested on Windows 11 with firmware `1.9.0.239`.

## Features

- Fetch device information and battery level (left, right, case): ✅
- Control noise cancellation (off / cancellation / awareness): ✅
  - With cancellation level: ✅
  - With dynamic cancellation: ✅
- Set double-tap action: ✅
  - w/ in-call options: ✅
- Set triple-tap action: ✅
- Set long-tap action: ✅
  - Split left/right configuration: ✅
  - Voice assistant, volume up/down: ✅
- Low-latency mode: ✅
- Equalizer: ✅
  - Built-in presets (Default, Bass, Treble, Voices): ✅
  - Custom presets / Fake built-in: ❓ (in testing)
- Dual connect (multipoint): ❓ (in testing)
- Sound quality preference (LDAC): ❓ (in testing)
- Wear detection (auto-pause): ❓ (in testing)
